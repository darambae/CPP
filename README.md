## Introduction

The C++ (CPP) modules at Ecole 42 are designed to introduce and deepen understanding of the C++ programming language through various projects, each focusing on different aspects of C++ programming, such as object-oriented programming (OOP), memory management, templates, exceptions, and more.

Les modules C++ (CPP) de l'école 42 sont conçus pour introduire et approfondir la compréhension du langage de programmation C++ à travers divers projets, chacun axé sur différents aspects de la programmation en C++, tels que la programmation orientée objet (POO), la gestion de la mémoire, les templates, les exceptions, et bien plus encore.

Ecole 42의 C++ (CPP) 모듈은 객체 지향 프로그래밍(OOP), 메모리 관리, 템플릿, 예외 처리 등 C++ 프로그래밍 언어의 다양한 측면을 소개하고 심화하는 것을 목표로 하는 여러 프로젝트로 구성되어 있습니다.

- Object-oriented programming (OOP) fundamentals and advanced concepts.
- Exception handling and error management.
- Template programming and generic functions.
- Complex data structures and memory management.
- Deep dive into C++98 standards.

- Approfondissement des normes C++98.
<br><br>
- 객체 지향 프로그래밍(OOP)의 기본 및 고급 개념.
